隐私政策

版本 1

PurrTV（以下简称"我们"）非常重视用户隐私。本隐私政策说明我们在您使用 PurrTV 应用时收集、使用和保护个人信息的方式。请您在使用本应用前仔细阅读本隐私政策。

一、信息收集

在您使用 PurrTV 时，我们可能收集以下信息：

1. 设备 ID：用于识别您的设备，实现登录设备管理与安全校验。

2. 服务器地址：您手动配置的 PurrTV 后端服务器地址，用于与您的私有服务器通信。

3. 登录凭证（Token）：登录成功后由服务器下发，用于后续请求的身份验证。

4. 设备名称与类型：用于在"在线设备管理"中展示当前登录设备。

5. 播放与搜索历史：由您的 PurrTV 服务器存储，本应用仅在本地缓存以提升使用体验。

我们不会收集您的浏览记录、通讯录、地理位置或其他与本应用功能无关的个人信息。

二、信息使用

我们收集的信息仅用于以下目的：

1. 实现用户登录、身份验证与会话管理。

2. 与您配置的 PurrTV 服务器通信，提供影视搜索、播放、收藏等功能。

3. 在多设备登录场景下提供设备管理能力。

4. 优化应用性能与用户体验。

三、数据安全

1. 登录凭证（Token）使用系统安全存储（iOS Keychain / Android Keystore / macOS Keychain）保存，并在支持回退的平台上加密存储。

2. "记住我"功能保存的用户名与密码使用 AES-256-CBC 加密后存储，密钥与设备身份绑定。

3. 尽管我们采取了合理的安全措施，但任何通过互联网传输的数据都无法保证 100% 安全。请妥善保管您的账户信息。

四、儿童隐私

我们不会故意收集儿童的个人信息。如果您是儿童的监护人，发现您的孩子向我们提供了个人信息，请联系我们，我们将及时删除相关信息。

五、政策变更

1. 我们可能不时更新本隐私政策。更新后的政策将在应用内通过版本号变更提示您重新确认。

2. 隐私政策的变更自您同意新版本起生效。

六、联系我们

如果您对本隐私政策有任何疑问或建议，可通过邮件 meowycn@163.com 与我们联系。

七、政策版本

1. 本隐私政策当前版本号为 1。

2. 当政策内容发生变更时，版本号将相应升高，届时您需要重新阅读并同意更新后的隐私政策方可继续使用本应用。

Privacy Policy

Version 1

PurrTV ("we") takes your privacy seriously. This Privacy Policy explains how we collect, use, and protect personal information when you use the PurrTV application. Please read this Privacy Policy carefully before using the application.

1. Information Collection

When you use PurrTV, we may collect the following information:

1. Device ID: used to identify your device and enable login device management and security verification.

2. Server address: the address of the PurrTV backend server you configure manually, used to communicate with your private server.

3. Login credentials (Token): issued by the server after a successful login, used to authenticate subsequent requests.

4. Device name and type: displayed under "Online Device Management" to show currently logged-in devices.

5. Playback and search history: stored on your PurrTV server; this application only caches them locally to improve the user experience.

We do not collect your browsing history, contacts, location, or any other personal information unrelated to the functionality of this application.

2. Use of Information

The information collected is used only for the following purposes:

1. Implementing user login, authentication, and session management.

2. Communicating with your configured PurrTV server to provide features such as media search, playback, and favorites.

3. Providing device management capabilities in multi-device login scenarios.

4. Optimizing application performance and user experience.

3. Data Security

1. Login credentials (Token) are stored using platform-secure storage (iOS Keychain / Android Keystore / macOS Keychain) and additionally encrypted on platforms that support a secure fallback.

2. Usernames and passwords saved by the "Remember Me" feature are encrypted with AES-256-CBC; the encryption key is bound to the device identity.

3. Although we take reasonable security measures, no data transmitted over the Internet can be guaranteed to be 100% secure. Please safeguard your account information.

4. Children's Privacy

We do not knowingly collect personal information from children. If you are a guardian of a child and discover that your child has provided personal information to us, please contact us and we will promptly delete the relevant information.

5. Changes to This Policy

1. We may update this Privacy Policy from time to time. Updated policies will be presented inside the application through a version-number change, prompting you to confirm again.

2. Changes to this Privacy Policy take effect once you accept the new version.

6. Contact Us

If you have any questions or suggestions about this Privacy Policy, please contact us by email at meowycn@163.com.

7. Policy Version

1. The current version number of this Privacy Policy is 1.

2. When the policy content changes, the version number will be incremented accordingly. At that point, you will need to re-read and accept the updated Privacy Policy before continuing to use this application.
